## 3. 비기능 요구사항 (NFR)

| ID | 분류 | 요구사항 | 측정/확인 방법 |
| --- | --- | --- | --- |
| NFR-01 | 개인정보 | 문서 이미지는 저장하지 않고 메모리에서만 처리한다. 녹음은 CLOVA Speech가 버킷에서 읽어야 하므로 임시 업로드 후 처리 완료 즉시 삭제하고, 늦어도 24시간 내 자동 삭제된다. 이름·주소·계좌는 DB에 저장하지 않는다. | 처리 후 Object Storage 조회, 버킷 수명주기 규칙 |
| NFR-02 | 보안 | 외부 API 키는 백엔드 환경변수에만 둔다. 프론트엔드는 외부 API를 직접 호출하지 않는다. | 번들 검색, 코드 리뷰 |
| NFR-03 | 성능 | F1 업로드→결과 15초 이내(시연 기준), 각 단계 진행 상태를 표시한다. | 시연 리허설 측정 |
| NFR-04 | 가용성 | 외부 AI 호출 실패 시 단계별 오류 메시지를 보여주고, 시연 모드에서는 캐시 응답으로 대체한다. | 키 제거 후 동작 확인 |
| NFR-05 | 비용 | 동일 입력의 AI 결과는 캐싱하고, 콘솔 예산 알림을 설정한다. | 콘솔 설정 확인 |
| NFR-06 | 사용성 | 360px 폭 모바일에서 모든 기능을 사용할 수 있다. | 개발자도구 모바일 뷰 |
| NFR-07 | 법적 고지 | "위법" 등 단정 표현을 쓰지 않으며, 법률 자문이 아님을 모든 결과 화면에 표시한다. | 프롬프트 규칙 + 응답 검사 |
| NFR-08 | 정확성 | 금액은 백엔드 코드로만 계산하며, LLM 설명에 계산 결과에 없는 숫자가 있으면 표시하지 않는다. | 단위 테스트, 숫자 검증 로직 |

## 4. 제약 사항

- 기간 2주, 팀원 4명.
- NCP AI 서비스는 서비스마다 인증 방식이 다름 (API Gateway 키 / 도메인별 Invoke URL·Secret / Studio API 키).
- 백문백답·생활법령 GW API는 2026년 신규 등록 → 응답 구조를 키 발급 당일 확인.
- CLOVA Dubbing은 실시간 API가 없음 → 콘텐츠 제작용으로만 사용.
- 최저임금은 매년 바뀜 → 연도별 상수로 관리하고 화면에 적용 연도 표시.

## 5. 범위 밖

로그인/회원 관리, 법률 상담 연결, 네이티브 앱, 지도(Maps), 원본 장기 보관.
