## FS-01. 계약서·급여명세서 점검 (FR-01~07, FR-13) · P0

### 화면 흐름

```
[업로드] ─► [추출 결과 확인·수정] ─► [점검 결과]
  사진 선택       시급/주 근로시간/        최저임금 충족 여부, 주휴수당,
  (카메라/앨범)    근무요일/휴게시간 편집    확인 필요 항목, 근거, 상담 안내, 🔊 듣기
```

### 처리 단계

| # | 주체 | 입력 | 처리 | 출력 | API |
| --- | --- | --- | --- | --- | --- |
| 1 | FE | 이미지 파일 | 형식·크기 검사(BR-01) 후 업로드 | — | API-03 |
| 2 | BE | multipart 이미지 | 메모리에서 base64로 바꿔 OCR 호출(AI-01). **이미지는 디스크·Object Storage에 저장하지 않음** (NFR-01) | OCR 원문 텍스트 | |
| 3 | BE | OCR 텍스트 | 규칙 기반 필드 추출(BR-02) | `extracted` 필드 + 신뢰도 | API-03 응답 |
| 4 | FE | `extracted` | 수정 가능한 폼으로 표시, 신뢰도 낮은 값 강조 | 확정 필드 | |
| 5 | BE | 확정 필드 | 최저임금·주휴수당 계산(BR-03, BR-04) | `calculation` | API-04 |
| 6 | BE | `calculation` + 키워드 | 백문백답 검색(FS-06) → Studio 설명 생성(AI-03) → 숫자 검증(BR-05) | `explanation`, `sources` | API-04 |
| 7 | FE | 결과 | 결과 카드·근거·상담 안내 표시, 🔊 버튼 → API-09 | — | API-09 |

### 업무 규칙

| ID | 규칙 |
| --- | --- |
| BR-01 | 허용 형식 jpg, jpeg, png, pdf / 최대 10MB / 1장. 초과 시 업로드 전 차단. |
| BR-02 | 필드 추출 규칙: `시급` = "시급/시간급/시간당" 뒤 숫자(쉼표·"만"·"원" 처리, 1,000~100,000원 범위만 인정), `근무요일` = "월~금"(범위)·"월,수,금"(나열)·"주 N일", `근무시간` = "HH:MM~HH:MM" 또는 "N시~N시"(자정 넘김 처리), `휴게시간` = "휴게" 뒤 "N분/N시간" 또는 시간 범위, `주 소정근로시간` = "주 N시간" 명시값 우선, 없으면 요일 수 × (근무시간 − 휴게시간). 명시값·직접 표기는 `high`, 계산으로 얻은 값은 `low`, 못 찾으면 `null`·`low`. |
| BR-03 | 최저임금: 적용 연도의 고시 시급과 비교. 연도 기본값은 **요청 시점의 연도**. 데이터 없는 연도는 400 오류. 금액은 `law-data/min-wage.json`(고용노동부 연도별 최저임금 CSV)에서 읽는다. 최저임금 조회(API-13)는 연도를 생략하면 올해 데이터가 없을 때 가장 최근 연도로 대체하고 `is_fallback`으로 알린다(직접 지정한 연도가 없으면 404). 고시는 확정됐지만 CSV에 아직 없는 연도(2027년 10,700원)는 `samples/raw/wage/announced.csv`로 보충한다. |
| BR-04 | 주휴: 주 소정근로시간 15시간 미만이면 대상 아님. 주휴시간 = min(주 소정근로시간, 40) ÷ 40 × 8. 주휴수당 = 주휴시간 × max(시급, 최저임금). |
| BR-05 | Studio 설명에 `calculation`에 없는 금액·숫자가 등장하면 해당 문장을 제거하고, 남은 문장이 없으면 템플릿 문구로 대체. |
| BR-06 | 단정 표현 금지: "불법", "위법", "신고하세요" 대신 "확인이 필요해요", "상담을 받아보세요". |
| BR-14 | 급여명세서 점검(API-14): 사용자가 확인·수정한 값으로 **코드가** 다음을 확인한다. ① 지급 항목 합 = 총액, 총액 − 공제 = 실지급액 ② 필수 항목(근로자 식별 정보·임금지급일·총액·항목별 금액, 근거 근로기준법 시행령 제27조의2)과, 금액이 달라지는 경우의 계산방법·공제 내역(확인 후보) ③ 시급·주 소정근로시간을 입력한 경우 최저임금 미달과 주휴수당 항목 유무(BR-03·04) ④ 위약금·교육비·강제 저축 등 이름의 공제(근거 근로기준법 제20·21·22·43조). 문장·금액은 코드 템플릿이 만들고 항목마다 법령 근거를 붙이며, 이름·지급일은 있는지만 보고 저장하지 않는다. 단정 표현 금지(BR-06). |

### 예외

| 상황 | 동작 |
| --- | --- |
| OCR 실패/텍스트 없음 | "글자를 읽지 못했어요. 밝은 곳에서 다시 찍거나 직접 입력해 주세요" + 빈 폼 제공 |
| 필드 일부 `null` | 해당 칸 빈칸으로 강조, 시급·주 근로시간이 비면 점검 버튼 비활성 |
| Studio 실패/타임아웃(20초) | 계산 결과만 표시 + "설명을 불러오지 못했어요" |
| 근거 검색 결과 0건 | 설명 없이 계산 결과 + 상담 안내만 표시 |

### 완료 조건

- **AC-01** 샘플 계약서 3종 중 3종 모두 시급이 추출되거나, 추출 실패 시 직접 입력으로 점검까지 완료된다.
- **AC-02** 시급 10,000원·주 20시간·2026년 → 미충족, 시간당 부족 320원, 주휴 4시간, 주휴수당 41,280원.
- **AC-03** 주 14시간 → 주휴 대상 아님, 주휴수당 0원.
- **AC-04** 결과 화면에 적용 연도, 고시 시급, 근거 출처 1개 이상(검색 결과가 있을 때), 상담 안내, 법률 자문 아님 고지가 표시된다.
- **AC-05** 계약서·명세서 이미지가 서버 디스크와 Object Storage 어디에도 남지 않는다.
- **AC-06** 설명 문장에 계산 결과에 없는 숫자가 나타나지 않는다.
- **AC-19** 급여명세서 점검: 지급 항목 합과 총액이 다르면 두 금액과 차이가, 총액에서 공제를 뺀 금액과 실지급액이 다르면 그 금액이 확인 항목으로 나온다. 시급 9,000원·주 20시간·주휴수당 항목 없음 → 최저임금 미달과 주휴수당 항목 없음이 함께 나온다. 모든 결과에 근거 출처가 붙는다.

| 2 | BE | Object Storage 업로드 → CLOVA Speech 장문 인식 요청(AI-02, 화자 분리) → `job_id` 반환 | API-05 |
| 3 | FE | 3초 간격 폴링 (최대 5분) | API-06 |

| 5 | FE | 타임라인(시각·화자·핵심 발언·분류) + 전체 대본 펼쳐보기 + 텍스트 내려받기 | |

### 업무 규칙

| ID | 규칙 |
| --- | --- |
| BR-07 | 허용 m4a, mp3, wav / 최대 200MB / `[미정]` 최대 10분. 동의 체크 없으면 업로드 버튼 비활성. |
| BR-08 | 화자 라벨은 "화자 A/B"로 표시, 사용자가 "나/사장님"으로 이름 변경 가능(화면 내에서만). |
| BR-09 | 타임라인 분류: `임금`, `근무시간`, `휴게·휴일`, `약속·지시`, `기타`. `기타`는 기본 숨김. |
| BR-10 | 작업 결과는 조회 후 1시간 뒤 서버 메모리에서 삭제(`[미정]` 저장 안 함 옵션). |
| BR-15 | 발언 근거(API-15): 타임라인 발언의 문장과 분류로 수동 Q&A 근거를 찾아 붙인다(발언당 최대 2건). 분류가 임금·근무시간·휴게·휴일·약속·지시이고 금액·시간·"안 줘도"·"나중에"·"알아서" 같은 표현이 있으면 '말로만 한 조건'으로 보고 계약서·문자로 남기도록 안내하며 서면 근거를 함께 보여 준다. 위반 여부를 판단하지 않고(BR-06), 서버에 저장하지 않는다. |

### 완료 조건

- **AC-07** 3분 샘플 녹음 업로드 → 3분 이내 타임라인 표시.
- **AC-08** 화자가 2명 이상으로 구분되어 표시된다.
- **AC-09** 동의 체크 없이 업로드할 수 없다.
- **AC-10** 처리 후 원본 녹음이 Object Storage에 없다.
- **AC-20** "이번 달부터 시급 만 원으로 할게"(분류 임금)를 보내면 `verbal_promise: true`, 서면으로 남기라는 안내, 관련 근거 1건 이상이 반환된다. 관련 없는 잡담(분류 기타)은 안내 없이 반환된다.

## FS-03. 빠른 음성 질문 (FR-11~13, FR-17) · P1

### 라우팅 (AI-05)

```
음성(≤60초) ─► CSR ─► 질문 텍스트 ─► Chatbot
                                      ├─ 매칭(신뢰도 ≥ 0.7, BR-11) ─► route = "faq"
                                      └─ 미매칭 ─► 백문백답 검색 ─► Studio ─► route = "studio"
                                  ─► (선택) Voice
```

| ID | 규칙 |
| --- | --- |
| BR-11 | Chatbot 응답이 기본 답변(fallback)이 아니고 신뢰도 ≥ 0.7이면 FAQ 경로. 임계값은 리허설 후 조정. |
| BR-12 | 녹음 60초 초과 시 클라이언트에서 자동 종료하고, 서버도 wav·mp3는 길이를 확인해 60초를 넘으면 400으로 거부한다(CSR은 60초 초과 파일을 `STT006`으로 거부함). 크기 10MB 이하. 실제로 mp3 인식을 확인했다. webm·ogg(브라우저 녹음)는 CSR이 읽는지 확인 전이며 서버 변환은 하지 않는다 → FE는 mp3·wav로 내보내는 것을 권장 `[미정]`. |
| BR-13 | CSR 결과가 빈 문자열이면 "잘 못 들었어요" + 텍스트 입력창으로 전환 (FR-17). |

### 완료 조건

- **AC-11** "주휴수당 받을 수 있어?" 음성 → FAQ 경로 답변 + 음성 재생.
- **AC-12** "주 3일 하루 5시간 일하면 주휴수당 나와?" → Studio 경로 + 근거 출처 표시.
- **AC-13** 마이크 권한 거부 시 텍스트 질문으로 같은 결과를 얻는다.
- 참고: '주 N시간', '주 N일 하루 M시간'처럼 내 근무시간을 말한 질문은 일반 FAQ가 맞지 않을 수 있어 Chatbot을 건너뛰고 코드로 주휴 대상 여부를 계산해 Studio에 넘긴다.

## FS-04. 다국어 표시 (FR-14) · P2

- 결과 화면 상단 언어 선택: 한국어(기본) / English / Tiếng Việt / 中文 `[미정]`.
- 번역 대상: 설명·확인 필요 항목·타임라인 문장. 숫자·고시 정보·출처 제목은 원문 유지.
- 번역 결과 캐싱(동일 문장+언어).
- **AC-14** 영어 선택 시 설명이 영어로 바뀌고 "원문 보기"로 한국어를 볼 수 있다.

## FS-05. 교육 영상 (FR-15) · P2

- CLOVA Dubbing으로 제작한 mp4를 `frontend/public/videos/`(또는 Object Storage 공개 경로)에 두고 메인 화면에 임베드.
- 스크립트는 백문백답 근로자 분야 내용으로 작성(데이터·콘텐츠 담당).
- **AC-15** 메인에서 영상 1편 이상 재생된다. 제작 후 Dubbing 프로젝트 그룹 삭제 확인.

## FS-06. 근거 원문 수집·검색 (FR-16) · P0

| 단계 | 처리 |
| --- | --- |
> 변경(2026-11-21): 법제처 생활법령 GW API(15159736·15160076)가 호출 오류(코드 04)로 사용 불가해 **국가법령정보센터 Open API(조문 원문) + 조문 기반 수동 Q&A**로 대체했다. 공공데이터포털 API가 복구되면 `source` 값(`QNA100` 등)만 추가해 합친다.

| 단계 | 처리 |
| --- | --- |
| 수집 | `python -m sync.law`가 국가법령정보센터 Open API로 근로기준법·시행령, 최저임금법·시행령, 근로자퇴직급여 보장법의 조문을 수집 → `law-data/law-articles.json`. `python -m sync.wage`가 고용노동부 연도별 최저임금 CSV를 변환 → `law-data/min-wage.json`. 수동 Q&A는 `law-data/qna-manual.json`(조문 id를 `relatedArticleIds`로 연결) |
| 로드 | 서버 시작 시 JSON을 메모리로 읽는다(`law_search.load_law_data`). 지금은 `backend/data/law-data/`를 읽고, Object Storage 모듈이 구현되면 버킷에서 읽는다 |
| 검색 | 질문·계산 결과 키워드(주휴, 최저임금, 휴게, 수습, 계약서 등)로 제목·키워드·본문 점수 매칭. 수동 Q&A(`MANUAL`)를 조문(`LAW_API`)보다 우선해 상위 N건 반환 (API-11). 단건 조회는 API-12 |
| 갱신 | 수동 재실행 (프로젝트 기간 내 1~2회), 반영은 서버 재시작 |

- **AC-16** 수집 후 `law-articles.json`에 근로기준법·최저임금법 조문이 들어 있고, `qna-manual.json`의 문항이 30건 이상이며 각 문항의 `relatedArticleIds`가 모두 실제 조문 id다.
- **AC-17** "주휴수당" 검색 시 관련 문항이 1건 이상 반환된다.
- **AC-18** `GET /wage/minimum`은 CSV 기반 값을 돌려주고, `year` 미지정에 올해 데이터가 없으면 가장 최근 연도로 대체하며 `is_fallback: true`로 표시한다.
