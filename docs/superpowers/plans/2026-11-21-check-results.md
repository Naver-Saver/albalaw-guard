# 점검 결과·공식 근거 화면

사용자가 승인한 6번 퍼블리싱. 이슈 #49, `feat/fe-49-check-results` 브랜치. 5번 추출 내용 편집 화면 위에 쌓는다. 기준은 결과 와이어프레임, FR-03·04, API-04 응답이다.

## 구현 범위

- 확인한 입력값과 고정 샘플 결과를 별도 표시한다. 실제 OCR·점검 요청이나 금액 계산은 하지 않는다.
- API-04 예시의 적용 연도·기준 시급·시간당 차이·주휴수당, 확인 항목, 설명을 표시한다.
- 공식 참고 자료의 제목·요약·원문 링크를 제공한다. 실제 문서 분석이나 백문백답 검색 결과라고 표시하지 않는다.
- HTTPS 정부 도메인 링크만 연결하고 계정 정보·비표준 포트·다른 프로토콜을 거부한다.
- 설명 없음·근거 없음·처리 중·오류 체험 상태를 제공한다. 근거가 없으면 설명을 숨긴다.
- 입력 편집으로 돌아가기와 질문 준비 화면, 상담 안내를 연결한다. 새 문서 선택 시 기존 세션을 초기화한다.
