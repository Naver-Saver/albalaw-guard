# 추출 내용 확인·수정 화면

사용자가 승인한 5번 퍼블리싱. 이슈 #45, `feat/fe-45-review-editor` 브랜치. 기준은 SVG 02, FR-02·03, FS-01 단계3·4, BR-02, API-03 응답과 API-04 요청 구조다.

## 구현 범위

- 원본 문서와 편집 폼을 나란히 구성하고 모바일에서는 세로로 배치한다.
- 샘플 체험은 합성 근로계약서와 샘플 OCR 응답을 함께 보여준다. 실제 파일에는 샘플 값을 넣지 않고 직접 입력으로 연결한다.
- 시급·주 근무시간·근무요일·휴게시간·적용 연도 입력과 신뢰도·미입력·수정 상태를 표시한다.
- 필수값·숫자 범위를 검증하고 원본 확인 동의를 받아야 진행 가능하다. 수정하면 동의를 무효화한다.
- 휴게시간 미입력은 요청에서 생략하고, 명시적인 0분과 구분한다. 금액은 계산하지 않으며 API-04 형태로 변환만 한다.
- 확인 후에는 입력값 요약만 표시한다. 실제 점검 결과·공식 근거·계산·AI 설명은 제공하지 않는다.
- 파일과 수정값은 작업 공간의 메모리에만 둔다. 관련 메뉴 사이에서는 유지하고 새 문서 선택 또는 소개 화면으로 나갈 때 해제한다. 렌더링용 객체 URL은 원본 컴포넌트 종료 때마다 해제한다.
