# 서비스 소개 화면 구현 계획

사용자가 승인한 3번 퍼블리싱 범위. 기준: 원본 SVG의 00a·00b, PRD F1·F4, FS-05, NFR-06·NFR-07. 공통 UI PR #30이 사용자 직접 확인과 CI 통과 후 머지된 main에서 시작한다.

## 구성

- 기존 React·TypeScript·Vite 및 공통 UI를 사용한다.
- 서비스 소개: 문구와 정적 문서 예시, 이용 시작·영상 안내 링크, 세 단계 이용 방법.
- 영상 안내: 전용 화면, 실제 파일 미제공 시 준비 상태와 글 안내. 임의 영상이나 가짜 재생 버튼은 넣지 않는다.
- 해시 경로로 소개·영상·작업 화면을 구분한다. 직접 링크·뒤로가기 및 알 수 없는 경로 복구를 지원한다.
- 실제 업로드·분석·번역·영상 제작은 범위 밖이다.

## 검증 한계

Windows 브라우저 연결을 사용할 수 없어 이번 단계의 실제 화면·키보드·360px 검증은 미완료다. 자동 검증 범위는 경로 해석과 서버 렌더링이며 시각적 검증을 대신하지 않는다. 2번 화면은 사용자가 직접 모두 정상이라고 확인했지만, 이 결과를 새 소개 화면 검증으로 간주하지 않는다.

## 코드 검토 보완

- 영상 URL을 video 요소에 직접 연결해 로드 실패가 해당 요소의 오류 처리로 이어지도록 수정했다.
- 최초 접속 시에는 포커스를 강제로 옮기지 않고, 앱 내 경로 이동 때만 새 본문으로 옮긴다.
- 경로·소개 링크·영상 유무 테스트 4개, lint, TypeScript production build가 통과했다. 실제 영상 로드 실패 이벤트와 시각적 동작은 브라우저 검증 범위로 남긴다.
